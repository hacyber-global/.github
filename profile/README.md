# Welcome to Hacyber Global Tech 🛡️

Secure, automated client onboarding and transaction portal interface.

---

### 🤖 Bot Menu Commands

Use the commands below directly in our chat interface to navigate services and submit transactions:

| Command | Description |
| :--- | :--- |
| `/start` | Launch the secure client portal interface & payment details |
| `/verify` | Check your current client verification status |
| `/portal` | Open the secure web transaction portal |
| `/support` | Contact Hacyber Global Tech administration |

---

### 💳 Payment & Verification Workflow

1. **Initiate Request:** Type `/start` to access payment details.
2. **Submit Receipt:** Send a screenshot or PDF receipt of your payment directly in the chat.
3. **Automated Review:** Our admin team reviews every transaction manually. Use `/verify` to check status.
4. **Instant Access:** Upon confirmation, your verified access link is automatically delivered to your chat.

---

### 🌐 Official Channels & Support
